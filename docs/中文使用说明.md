# Apple TV 遥控器变身 Mac 万能遥控器（一键使用包）

> 把吃灰的 Apple TV 遥控器，变成一台 Mac 的**万能遥控器**：一个按键，在不同 App 里有不同含义；
> 圆形触控板就是鼠标，转圈就能滚动；还可以按住 Siri 键直接语音输入（配合 Codex / 微信输入法）。

本包 = **软件本体（HyperVibe / SiriRemoteForge）＋ 已调好的整套按键映射（18 个应用模式）＋ 中文使用说明**。

---

## 一、这是什么

**HyperVibe**（上游项目名 SiriRemoteForge）是一款 macOS 应用，它接管第三代 Apple TV 遥控器的蓝牙连接，
把它的 13 个按键、圆形触控板、滑动全部变成你可以自由定义的 Mac 操作。配置保存在一个 JSONC 文件里，
**保存即生效、无需重启**。

本仓库在开源上游基础上，额外内置了一套**中文按键映射预设**（`examples/config.codex-tv-remote.jsonc`），
覆盖浏览器、Chrome、Codex、WPS 表格、WPS 文字、微信、B 站/腾讯视频/优酷、音乐、Keynote 演示、
终端、访达、看图等场景，装完即可用。

### 核心能力

- **全按键可重映射**：点按 / 双击 / 三击 / 长按（最多 3 段，各段时长可调）。
- **按应用切换**：不同 App 自动切换不同映射（如浏览器里返回=网页后退，Codex 里返回=删除一字）。
- **触控板即鼠标**：滑动手势控制光标，外圈转圈 = 滚动。
- **应用圆盘**：按 TV 键弹出径向应用启动器，一键切 App。
- **窗口管理**：双击/长按可最大化、左右分屏、最小化、居中还原。
- **语音输入**：按住 Siri 键 = 按住语音快捷键（预设 `右 Option`），配合 Codex / 微信输入法直接听写。

> 注意：本工具使用了 macOS 私有框架（MultitouchSupport、SkyLight），**不能上架 App Store**，
> 需要自行构建或使用 GitHub Release 的 beta 包，首次打开需右键 →「打开」。

| --- | --- |
| Mac | macOS 13（Ventura）或更高，Apple 芯片或 Intel 均可 |

| 构建工具 | Xcode 命令行工具（`xcode-select --install`） |
| 蓝牙 | 先让遥控器和 Mac 完成蓝牙配对 |
| 权限 | 辅助功能 + 输入监控（首次运行系统会询问，需手动授权） |

## 三、安装步骤

### 1. 获取代码

```sh
git clone -b codex-siri-remote-ptt https://github.com/zer0-lyz/SiriRemoteForge.git
cd SiriRemoteForge
```

> 重要：请使用上面的分支名 `codex-siri-remote-ptt`（默认分支 `main` 不包含本套预设）。

### 2. 构建 App

```sh
cd app
./build.sh
./create_app_bundle.sh
xattr -cr HyperVibe.app
ditto HyperVibe.app /Applications/HyperVibe.app
xattr -cr /Applications/HyperVibe.app
codesign --force --deep --sign - /Applications/HyperVibe.app
```

### 3. 安装映射预设（自动备份旧配置）

```sh
cd ..   # 回到仓库根目录
scripts/install-codex-tv-config.sh
```

脚本会把 `examples/config.codex-tv-remote.jsonc` 复制到
`~/.config/siriremote/config.jsonc`，并自动备份原有配置。

### 4. 授权 macOS 权限

```sh
open 'x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility'
open 'x-apple.systempreferences:com.apple.preference.security?Privacy_ListenEvent'
```

在系统设置中给 `/Applications/HyperVibe.app` 打开：

- 辅助功能
- 输入监控

### 5. 配对遥控器

1. 打开 Mac 的「系统设置 → 蓝牙」。
2. 让遥控器靠近 Mac，在设备列表中找到 Siri Remote 并连接。
3. 如果搜不到，长按遥控器「返回 + 音量上」数秒进入配对状态。

### 6. 启动并验证

```sh
open -a /Applications/HyperVibe.app
tail -n 60 /tmp/hypervibe.log
```

看到以下信号表示正常：

```text
Input Monitoring access: granted
IOHIDManagerOpen success
MediaKeyInterceptor: event tap installed and enabled
```

## 四、这套映射说明书（预设按键含义）

> 「ring」指遥控器外圈环（上/下/左/右滑动），「button」指物理按键。
> `.hold`=长按，`.double`=双击，`.triple`=三击。

### 全局（所有 App 通用）

| 操作 | 含义 |
| --- | --- |
| 返回键（点按） | Esc 取消 |
| 返回键（长按） | 关闭窗口 |
| TV 键（点按） | 应用圆盘（径向应用启动器） |
| TV 键（双击） | 鼠标右键 |
| TV 键（长按） | 系统级应用切换（Cmd+Tab） |
| Siri 键（按住） | 语音听写（右 Option） |
| Siri 键（双击） | 确认（回车） |
| Siri 键（三击） | 取消（Esc） |
| 播放键（点按） | 播放/暂停 |
| 播放键（长按） | 打开音乐 |
| 静音键 | 静音 |
| 音量 +/- | 系统音量 |
| 环-上/下/左/右 | 方向键 |
| 环-左/右（双击） | 切换上一个/下一个桌面 |
| 环-上（长按） | 调度中心 |

### 浏览器（Safari / Edge）

| 操作 | 含义 |
| --- | --- |
| 返回键（点按） | 网页后退 |
| 返回键（双击） | 网页前进 |
| 环-左/右 | 上个/下个标签页 |
| 环-上/下 | 快速上滚/下滚 |
| 环-下（双击） | 关闭标签 |
| 环-上（双击） | 恢复刚关闭的标签 |
| 电源键 | 关闭标签（Cmd+W） |

### Chrome

返回键=删除一字、双击=网页后退；静音键=地址栏/搜索（双击=刷新）；播放键=前往；
音量键=缩放；环=标签页切换/快速滚动。

### Codex

| 操作 | 含义 |
| --- | --- |
| 返回键（点按） | 删除一字 |
| 返回键（长按） | 撤销编辑（Cmd+Z） |
| 静音键 | 清空输入框 |
| 播放键 | 发送（回车） |
| Siri 键 | 按住听写 |
| 环-上/下 | 上个/下个对话 |
| 环-左 | 切换边栏 |
| 环-右 | 显示/隐藏侧边栏 |
| 音量 +/- | 上翻页/下翻页 |

### WPS 表格（wpsSheet）

返回键=删除（长按=撤销）；环=标签页切换；音量键=切换左右 Sheet；
静音键=进入「左右滚动」层（再按一次回来）；环上/下=翻页。

### WPS 文字（wpsWriter）

静音键=进入「选择文字」层（环+音量键=四向扩选）；音量下=下一条修订（双击=接受修订）；
音量上=插入批注（双击=批量批注）；环=标签页切换/翻页。

### 微信 / 企业微信

播放键=发送；静音键=搜索（双击=新建聊天）；返回=删除（长按=撤销输入）；
环上/下=切换会话；音量键=翻聊天记录。

### 视频（B 站 / 腾讯视频 / 优酷）

播放键=播放/暂停；返回键（双击）=全屏；环左/右=快退/快进（按住连续）。

### 其他

- **音乐**：播放键=播放/暂停，环左/右=上一首/下一首，静音=静音。
- **演示（Keynote / PowerPoint）**：环左/右=上一页/下一页，播放键=播放/暂停，TV 键=全屏。
- **终端**：返回=连续删除，环下（双击）=关闭标签，环上（双击）=恢复标签。
- **访达**：返回=上级文件夹，播放键=打开，静音键=快速预览，音量键=复制/粘贴。
- **看图（预览）**：环=上一张/下一张/翻页。

## 五、怎么改按键

编辑 `~/.config/siriremote/config.jsonc`，**保存立即生效**，无需重启：

```jsonc
// 例如：把「返回键」改为 F5
"button.menu": { "action": "keystroke", "keys": "f5" }
```

也可以打开 App 里的「设置」窗口，用图形界面点选每个按键来修改。

## 六、常见问题

**按键完全没反应？**

1. 遥控器是否已通过蓝牙连到当前 Mac；
2. HyperVibe 是否在运行（`pgrep -fl HyperVibe`）；
3. 「辅助功能」「输入监控」是否已授权；
4. 是否同时运行了多个 HyperVibe。

**不同 App 没按预设切换？**

确认 `~/.config/siriremote/config.jsonc` 里的 appProfiles 是否完整，重新执行
`scripts/install-codex-tv-config.sh`。

**Siri 键语音不生效？**

预设的语音快捷键是「右 Option」，需要在 Codex 或微信输入法的语音设置里把快捷键改成
「右 Option」。
